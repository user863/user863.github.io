# Buryat letters (prototype)

A privacy-first, offline-first prototype for learning Buryat. This repository is the built web app for
https://user863.github.io. It makes no network requests while you use it, collects no analytics and keeps your progress on your device.

- Code and original artwork: MIT (`LICENSE`).
- Language data, fonts, sounds and the speech model keep their own licences: see `THIRD_PARTY_NOTICES.md` (also on the app's Credits screen).
- All language content is unreviewed by native speakers.
- Independent project, not affiliated with Duolingo.
